Windows display and sound guide

Switch a Windows display and audio output together

Win+P can change which screen Windows uses, but it does not give you a named setup that also selects the playback device. A combined profile turns those repeated steps into one action.

Short answer: Use Win+P when you only need PC screen, Duplicate, Extend, or Second screen. Use a display-and-audio profile when every screen change also requires a specific speaker, TV, headset, or virtual playback output.

The normal Windows method

Press Windows key + P and select PC screen only, Duplicate, Extend, or Second screen only. Then open the sound-output control and choose the playback device. This works, but it is two separate decisions every time.

That separation matters for a desktop PC connected to both a desk monitor and a TV. The desired screen action and the desired sound destination often form a pair: desk display plus speakers, TV plus HDMI audio, or extended screens plus a headset.

What a combined profile should save

  • the Windows display action;
  • the target Windows playback output;
  • a clear name such as Desk, TV, or Dual Screen;
  • whether an optional companion such as Voicemeeter should start;
  • a tray command so the profile is available without reopening settings.

How Display / Audio Switcher works

Display / Audio Switcher detects attached displays and Windows playback outputs, then lets you save three editable profiles. Each profile pairs one of the four standard Windows display actions with one playback device.

Run a profile from the main window or the system tray. The app uses Windows commands rather than inventing a new display mode, so PC-only, second-screen, duplicate, and extend remain recognizable. Voicemeeter support is optional; the normal switching package is self-contained.

Important limits

The app does not route individual programs to different speakers and does not move a particular window between monitors. It changes the Windows display action and the default playback output for the whole setup. The release is portable and unsigned, so Windows may show an unknown-publisher or reputation warning.
