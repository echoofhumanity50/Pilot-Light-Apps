Windows profile guide

Save Windows display and audio profiles

A profile gives a familiar name to a repeated combination: which display action Windows should use and where the default sound should play.

Short answer: Identify your three most common setups, give each one a result-based name, pair a standard Windows display action with a playback output, and test every profile in both directions.

Good profile names describe the result

Names such as Display 2 or Device 4 become confusing when cables or drivers change. Names such as Desk, TV, Presentation, Dual Screen, Headset, or Speakers describe what you expect to happen.

Three practical profile examples

  • Desk: PC screen only with desktop speakers or a headset.
  • TV: second screen only with TV or receiver HDMI audio.
  • Dual Screen: extend with speakers, a headset, or a virtual playback output.

The display action is one of the ordinary Windows choices: PC-only, second-screen, duplicate, or extend. The audio selection is a playback output already visible to Windows.

Build and test the profiles

  1. Power on the hardware and let Windows detect it.
  2. Refresh the display and audio lists.
  3. Select the display action and playback output for the first profile.
  4. Name and enable the profile, then save.
  5. Repeat for the other common setups.
  6. Run every profile and verify both picture and sound before relying on it.

Display / Audio Switcher exposes enabled profiles in the settings window and system tray. If a profile uses a Voicemeeter output, the app can optionally launch Voicemeeter; that software is not required for ordinary Windows outputs.

Keep portable-app paths stable

The stable release is a portable ZIP. Extract the complete folder before running the EXE and keep the included files together. If you enable Start with Windows, turn that option off before permanently moving or deleting the extracted folder so the saved startup path does not point to the old location.

What to verify after a Windows or driver update

Device names and availability can change when graphics or audio drivers are replaced. If a profile stops producing the expected result, refresh the device lists, confirm the target output still exists, and save the profile again.
